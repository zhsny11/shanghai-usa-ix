## 沪美IX是什么：不是普通美国VPS

沪美IX 在 Mkcloud 官方口径里叫"上海上云互联优化-美国BGP专线（流量计费/共享带宽）"，所属产品线在知识库标签里被归为"沪美IX专线"。它的入站仅在上海的互联网交换中心（IX，如 SHIXP 等）内宣告，并不是三大运营商的常规公网路由。

这带来三个关键后果：

- 只有加入对应 IX 的云厂 BGP 网络才能从国内连入这台 VPS。三大运营商的宽带、移动网络、联通网络默认情况下是连不上的。
- 一旦连入，云厂内网到这台机器的网络质量通常远好于公网，再从这台机器的出口（美国 BGP 网络）出去访问美区服务，整段路径会比普通跨境链路稳定很多。
- 因为入口走的是云厂网络，所以适合的"前端"就是阿里云、腾讯云、华为云、火山云、UCloud、百度云等云厂商在国内的轻量或 CVM 实例。

需要提醒的是：Mkcloud 文档对"沪美端内延迟"给出的参考是 124~134ms。这只是端到端参考值，不等于你从办公室访问美区服务的最终延迟，也不等于它和所有美国网站的有效延迟。把它当成衡量"链路本身是否在合理区间"的标尺更合适。

## 谁适合买沪美IX，谁其实不需要

直接引用官方知识库对沪美专线的场景定位：

- 美区店铺后台、海外办公和授权 API 访问
- 从 VPS 发起素材上传、文件传输、业务数据同步
- 针对美国服务的客户端测试与运维操作

反过来，也有几条硬性限制，在购买之前必须认清：

- 出口 IP 不支持外部连入。也就是说不能拿它挂买家页面、支付回调、公开网站、游戏服务端。
- 入口只允许云厂 BGP 网络接入。家用宽带、三大运营商默认无法直连。
- 跨境业务使用需按用途核验权限与数据合规，并不是"想做啥就做啥"。
- 需中国身份信息实名，禁止用于机场、回国等违规用途。

换句话说，如果你"只是想找个便宜的美国 VPS 翻出去用"，沪美IX 不是正解——它是为已经有云厂资源、需要稳定跨境通道做事儿的用户准备的。

## 常见问题

**沪美IX 可以用家用电信宽带直接连吗？**
不可以。入口仅在 IX（互联网交换中心）内宣告，三大运营商的家用宽带默认不在 IX 网络内，无法直接路由到入口 IP。

**阿里云能不能做前置？**
文档目前标注"阿里云国内全网（暂时不通）"。其他可选前置以腾讯云国内全网、华为云华东、UCloud 华东、火山云华东、百度云国内全网更稳。

**端内延迟 124~134ms 是指什么？**
指的是 Mkcloud 给出的"端内参考延迟"，反映链路本身的物理与路由水平。它不等同于你访问某个美国网站的最终延迟，也不等于全程 RTT 实测值。把它当成链路是否在合理区间的标尺，不要当成承诺值。

**超量之后怎么办？**
超量按当前公开策略停机。可在工作台自助购买一次流量重置（按当期单价续一段用量），或者补差价升档到更高流量套餐。也可以联系工单升级。

**能拿来挂网站吗？**
不能。出口 IP 不支持外部连入，沪美IX 只能走"出站访问美区服务"这一种用法。如果你需要的是可直接建站的美国线路，思路要换。

**月付、年付怎么选合适？**
如果你对实际带宽峰值和真实流量还想再观察 1~2 个月，可以先月付 1TB 一档。稳定后切年付并升档到 2TB / 3TB，多数情况下会比一直月付便宜一些。
